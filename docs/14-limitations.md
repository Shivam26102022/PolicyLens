# 14. Scope and Known Boundaries

> A precise statement of what this prototype covers, what the evidence supports, and where it stops. It was built for a bounded assessment with limited time and resources, and every boundary below is a deliberate scope choice with a stated production path. Companion to the [system card](11-system-card.md).

- **Corpus:** four countries (SGP, MYS, IDN, IND), 2015–2025 statistics and four World Bank PDF reports. Questions outside it should be abstained on.
- **Retrieval:** 40 anchored cases were measured (run `7437acdc`, after fixing a per-source cap bug). Recall@6 is 0.65–0.70 for BM25, dense and hybrid and 0.75 with the local cross-encoder; PDF-page anchors are the weak spot (0.27–0.47) while structured rows reach 1.00. The reranker is off on the Vercel deployment. Anchors name a single marker, so valid alternative passages count as misses. No case has graded relevance labels (nDCG uses binary relevance). Agent accuracy, evidence completeness and judge scores have not been regenerated since the fix.
- **Agent quality:** Latest registered run `ad3163da-7b37-440d-b317-83b1f0075d97` used `agent-v4` and the non-agent baseline (`gpt-6-luna`, seed 0, 67 cases). All-attempt expected-behaviour accuracy is 0.866 for the agent and 0.433 for the baseline (paired difference +0.433, 95% bootstrap [+0.299, +0.567], discordant 31/2, exact McNemar p<0.0001); failed generations count as incorrect. The previous `agent-v3` run (`18454f3c`) scored 0.881 against 0.418; the two agent scores are statistically indistinguishable. AI-judged groundedness is 3.54/5 and relevance 4.58/5 (scored by the generating model, so a screening signal). Dev/test accuracy is 0.853/0.879 for the agent, so the earlier dev-over-test gap is not present in `agent-v4`. Lowest categories: adversarial citation (0.333) and the single-case conflict and local-model-failure categories (0.000), then invalid MCP arguments, multi-source synthesis, multi-step tool use, unauthorized source and user injection (0.667 each); categories of three or fewer cases are descriptive. The 67 cases are AI-drafted from verified sources and human-approved. The run uses the current `agent-v4` prompt. The evaluation cases are single-turn, so the follow-up rewrite step is not exercised by them.
- **Human review:** all 67 case definitions are human-approved under `reviewer-user`. A stratified sample of 19 deployed-app answers was scored against the documented rubric by two recorded reviewers (38 records, `data/manifests/evaluation-review-manifest.json`). Both sets of scores start from the same AI-drafted scoring, so their agreement shows consistency of confirmation, not independent inter-rater reliability; a blind second reviewer would establish that. The AI judge used the generating model and is a screening signal.
- **Tooling:** one read-only statistics tool; at most four geographies per call and eight calls per run. MCP fault-injection cases (timeout, malformed response) are covered by tests but cannot be triggered in live runs.
- **Provider:** the Azure deployment rejects `temperature=0`; provider content-filter rejections surface as `blocked`. Recognized prompt-injection text is removed before provider submission, but heuristic filtering is not general protection. There is no automatic fallback to another provider. The MLX route cannot run on this Linux host.
- **Identity:** access control is a workspace header plus a data-use acknowledgement; production would need SSO and RBAC.
- **Data:** PDFs are parsed without OCR; ILO figures are modelled estimates, not survey results.
- **Reproducibility:** runs before the first git commit recorded no code revision; later runs record the git revision and a source-tree fingerprint.
- PolicyLens must not be the final authority for consequential legal, regulatory, safety, eligibility, enforcement, benefits, or funding decisions.
